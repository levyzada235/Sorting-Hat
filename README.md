# Chapeu-Seletor
Esse projeto é um programa que simula o teste das Casas de Hogwarts do Chapéu Seletor, com base nas respostas que o usuário fornecer.
As perguntas são baseadas no universo de Harry Potter e avaliam algumas características do usuário para assim definir qual Casa de Hogwarts combina mais com ele.
Projeto proposto pela plataforma de ensino Codedex.
